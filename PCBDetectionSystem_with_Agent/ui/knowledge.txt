# PCB 缺陷检测系统知识库

本文件是系统的内置知识库，回答用户关于缺陷类型、参数含义、系统使用等知识性问题时，请以本文件内容为准。

## 系统使用说明

- 系统基于 YOLOv8 对 PCB 裸板图像进行缺陷检测，输入支持三种形式：
  单张图片、只含图片的文件夹（jpg/jpeg/png）、mp4 视频。
- 检测完成后，原始画面与检测画面会同时展示，历史记录写入
  `history/history.json`，临时结果存放在 `temp_file/`。
- 检测参数：
  - conf（置信度阈值）：取值 0-1，默认 0.25。值越小，检测越宽松，
    漏检越少但误报可能增多；值越大越严格。
  - max_det（最大缺陷数量）：单张图最多输出的缺陷数，默认 5。
  - 保存选项：可勾选是否保存 JSON 标注文件与 txt 标注文件。
  - 显示选项：可控制结果图上是否显示类别标签与置信度。
- 模型选择：
  - n（快速）：PCB_YOLO_n_1024_CAwithCBAM.pt，速度最快，精度较低；
  - s（兼顾）：PCB_YOLO_s_1024_CAwithCBAM.pt，速度与精度平衡；
  - m（精确）：PCB_YOLO_m_1024_CAwithCBAM.pt，精度最高，速度最慢。
  - 也可把自定义模型放入 `model/custom_models/`，界面会自动列出。
- 摄像头：打开摄像头后点击检测按钮，可进行实时检测；检测帧会保存到
  `temp_file/camera/`，注意控制检测量以免占满硬盘。

## 缺陷类型

- Missing_hole（漏孔）：PCB 上需要钻孔的位置未钻出孔洞，属于漏工序缺陷。
  外观表现为焊盘或过孔位置没有孔。
- Mouse_bite（鼠咬）：板边或焊盘边缘的铜箔呈凹陷状缺口，形似被老鼠咬过，
  通常由蚀刻过度或机械损伤造成。
- Open_circuit（断路）：铜箔线路发生断裂，导致电气连接中断，是严重缺陷。
- Short（短路）：本应绝缘的两条线路之间意外连通，会造成电路功能异常，
  属于严重缺陷。
- Spur（毛刺）：线路边缘出现多余的铜箔凸起，可能引发放电或短路风险。
- Spurious_copper（多余铜）：板面上残留的无关铜箔，通常由蚀刻不彻底导致。

# 缺陷检测（Defect Detection）知识库文档


## 一、概述

### 1.1 什么是缺陷检测

缺陷检测是指通过人工或自动化手段，对工业产品在生产过程中产生的各类瑕疵进行识别、定位和分类的技术过程。在复杂的工业生产过程中，由于设备误差、工艺波动等原因，产品表面、边缘或内部可能出现气孔、凹坑、划痕等缺陷。这些缺陷不仅影响产品的外观质量，更会降低其性能和使用价值。

### 1.2 缺陷检测的重要性

缺陷检测是保障产品质量、提高企业竞争力的关键手段。产品缺陷会导致资源浪费、收入减少、客户满意度下降，同时增加额外的检测成本。在智能制造和“工业4.0”背景下，产品质量和生产效率已成为企业竞争的核心要素。

### 1.3 从人工检测到智能检测

传统缺陷检测依赖人工目视检查，存在抽检率低、准确性不高、实时性差、效率低、劳动强度大等弊端。人工检测不仅成本高昂，而且检测结果具有主观性，难以满足大规模质量检验的需求。

机器视觉和深度学习技术的快速发展，为缺陷检测提供了高精度、高效率的自动化解决方案。AI质检正从高端汽车、航空领域向电子、模具等行业普及。


## 二、缺陷检测方法分类

根据技术演进路径，缺陷检测方法可分为三大类：

### 2.1 传统图像处理方法

传统方法基于数字图像处理技术，主要包括图像预处理、图像分割和特征提取等步骤。常见技术包括：
- **图像预处理**：去噪、增强、灰度变换等
- **图像分割**：阈值分割、边缘检测、区域生长等
- **特征提取**：纹理特征、颜色特征、形状特征等

**局限性**：对光照变化、背景复杂等场景鲁棒性较差，泛化能力有限。

### 2.2 传统机器学习方法

机器学习方法通过人工设计的特征来描述缺陷，再使用分类器进行判别。主要包括：
- **基于点距离的算法**：如K近邻（KNN）
- **基于超平面的算法**：如支持向量机（SVM）
- **基于树的算法**：如决策树、随机森林
- **基于神经网络的算法**：早期浅层神经网络

**局限性**：仍然依赖人工特征工程，特征设计质量直接影响检测效果。

### 2.3 深度学习方法

深度学习通过多层神经网络自动学习数据的层次化表征，无需人工设计特征。是目前缺陷检测领域的主流方法。

深度学习模型按任务类型可分为：
- **缺陷分类（Classification）** ：判断图像中是否存在缺陷及缺陷类型
- **缺陷定位（Localization）** ：用矩形框标记缺陷位置
- **缺陷分割（Segmentation）** ：在像素级别精确描绘缺陷区域


## 三、深度学习核心技术与模型

### 3.1 卷积神经网络（CNN）

CNN是目前工业缺陷检测中应用最广泛的深度模型，在缺陷分类任务中准确率可达95%以上，在分割任务中mIoU可达85–91%。主流CNN变体包括ResNet、DenseNet、Inception等。

CNN的优势在于能够自动学习从底层边缘、纹理到高层语义的分层特征表示，在各类工业表面（金属、纺织品、PCB等）的缺陷检测中均取得了高精度和实时性能。

### 3.2 目标检测模型（YOLO系列）

YOLO（You Only Look Once）系列模型在缺陷检测中广泛应用，可实现端到端的缺陷定位与分类。近年来YOLOv5、YOLOv8、YOLOv10等版本持续演进，在精度和速度之间取得了更好的平衡。

### 3.3 分割模型

用于像素级缺陷检测的模型主要包括：
- **编码器-解码器结构**：如U-Net
- **金字塔网络**：如FPN
- **注意力机制**：如Transformer-based分割模型

### 3.4 无监督与异常检测方法

在实际工业场景中，获取大量带标签的缺陷数据非常困难。无监督学习因此成为研究热点。

主流无监督方法包括：
- **生成对抗网络（GANs）** ：通过学习正常样本的分布，将偏离分布的样本识别为缺陷
- **扩散模型（Diffusion Models）** ：通过逆向扩散过程检测异常
- **自编码器（Autoencoders）** ：通过重构误差判断异常

此外，半监督学习、弱监督学习和自监督学习在数据稀缺场景中也展现出良好前景。

### 3.5 新兴技术方向

- **Transformer架构**：将NLP领域的注意力机制引入视觉缺陷检测
- **大语言模型与基础模型**：利用大规模预训练模型进行缺陷检测
- **少样本学习（Few-shot Learning）** ：在仅有少量标注样本的情况下实现缺陷检测
- **知识图谱与检索增强**：结合领域知识提升检测的准确性和可解释性


## 四、数据集与评估指标

### 4.1 常用数据集

工业缺陷检测数据集按类型可分为：

**多材料综合数据集**：涵盖多种工业产品的缺陷样本

**单材料专项数据集**：
- **NEU-CLS**：钢材表面缺陷数据集
- **CrackForest**：裂纹检测数据集
- **MT-Defect**：包含1344张灰度图像，涵盖5类缺陷
- **PCB-AoI**：PCB光学检测数据集，包含1271张600×600像素图像
- **DeepPCB**：PCB缺陷检测数据集

### 4.2 评估指标

缺陷检测算法的性能评估主要关注**准确性**和**效率**两个方面。

#### 准确性指标

基于混淆矩阵的四项基本指标：

| 指标 | 含义 |
|------|------|
| **TP（真阳性）** | 实际有缺陷，正确检测为有缺陷 |
| **TN（真阴性）** | 实际无缺陷，正确检测为无缺陷 |
| **FP（假阳性）** | 实际无缺陷，错误检测为有缺陷（误报） |
| **FN（假阴性）** | 实际有缺陷，未能检测出（漏报） |

**分类任务常用指标**：
- **精确率（Precision）** ：TP / (TP + FP)
- **召回率（Recall）** ：TP / (TP + FN)
- **F1-Score**：精确率和召回率的调和均值

**检测任务常用指标**：
- **平均精度（AP）** ：每个缺陷类别的检测精度
- **平均精度均值（mAP）** ：所有类别AP的平均值

**分割任务常用指标**：
- **平均交并比（mIoU）** ：预测分割图与真实标注的重叠程度，能同时惩罚过度分割和欠分割

#### 效率指标
- 模型参数量（Parameters）
- 推理速度（FPS）
- 计算复杂度（FLOPs）


## 五、典型应用场景

### 5.1 金属材料缺陷检测

金属表面缺陷（如划痕、凹坑、裂纹等）检测是最常见的应用场景。深度学习模型在钢材、铝材等金属表面缺陷检测中取得了显著成果。

### 5.2 电子元器件检测

- **PCB电路板**：检测虚焊、短路、断路等缺陷
- **晶圆**：检测微米级缺陷
- **显示面板**：检测玻璃盖板、显示面板的微米级瑕疵

### 5.3 纺织品检测

检测布匹上的疵点、色差、破洞等缺陷

### 5.4 焊接质量检测

焊缝缺陷检测是航空航天、汽车制造等领域的关键环节

### 5.5 透明与反光部件检测

玻璃、镜面等透明或反光材料的缺陷检测是技术难点之一

### 5.6 无损检测（NDT）

- **X射线检测**：检测工业部件的内部缺陷
- **漏磁检测**：适用于铁磁性材料的缺陷检测


## 六、工程部署关键挑战

### 6.1 数据层面的挑战

- **标注数据稀缺**：工业场景中获取大量高质量标注数据成本高昂
- **类别不平衡**：缺陷样本远少于正常样本
- **数据质量**：光照变化、背景复杂等因素影响检测稳定性

### 6.2 性能层面的挑战

- **实时性要求**：生产线对检测速度有严格要求，需在精度和速度间取得平衡
- **边界模糊**：异常与正常区域的过渡带难以界定
- **计算资源受限**：边缘设备部署需考虑模型轻量化

### 6.3 部署层面的挑战

- **模型可靠性**：需解决模型过度自信和校准不良的问题
- **人机协同**：建立“人在回路”（Human-in-the-loop）框架，结合人工审核提升可靠性
- **领域适配**：不同产品、不同产线需要模型适配和微调


## 七、未来发展趋势

1. **大模型与基础模型应用**：利用大规模预训练模型提升缺陷检测的泛化能力和准确性

2. **多模态融合**：结合3D视觉、红外、X射线等多模态信息进行综合判断

3. **轻量化与边缘部署**：面向工业现场的低算力设备，开发高效轻量级模型

4. **知识增强**：将行业标准、生产工艺知识融入模型，提升检测的可解释性和准确性

5. **零样本/少样本学习**：进一步降低对标注数据的依赖，实现快速部署

6. **端到端自动化**：从数据采集、模型训练到部署推理的全流程自动化
